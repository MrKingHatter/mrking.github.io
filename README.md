# mrking.dk

Personal website served via [GitHub Pages](https://pages.github.com/) at **[mrking.dk](https://mrking.dk)**.

## Overview

A lightweight static site used as a web development playground — experimenting with HTML, CSS, and JavaScript.

## Structure

```
index.html   – Landing page
about.html   – About / site details
styles.css   – Shared stylesheet
images/      – Image assets
CNAME        – Custom domain configuration (mrking.dk)
```

## Local Development

Open `index.html` in a browser, or serve locally:

```bash
npx serve .
```

## Deployment

Pushing to the `main` branch automatically deploys via GitHub Pages. The custom domain is configured through the `CNAME` file and DNS settings.
